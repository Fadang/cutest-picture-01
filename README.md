# cutest-picture-01

A make.fun bounty entry: a stdlib-only Python program that procedurally draws a cute chibi kitten with a chick companion as a 1024x1024 PNG.

## Run

```bash
python3 main.py
```

This writes the image to `/output/entry.png`.

It uses only the Python 3.13 standard library, so no third-party dependencies are needed.
